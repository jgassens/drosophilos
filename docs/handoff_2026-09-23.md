## Root cause common to every failed trial
The guards (`guarded_pulse`, go chains and commit gates) veto on a pair's FALSE rail only, so
a pair dark on both rails reads as true. Every change to when a request rail is cleared or
re-lit opened such a window somewhere (extra START, duplicate commit, stale SEL condition).
